# spectral reflectance

This repository contains an R/RStudio workflow for processing spectral reflectance measurements and generating derived outputs.

## Folder structure

* `R/`
  Reusable R functions shared across scripts (helpers, utilities).

* `scripts/`
  Step-by-step scripts that run the workflow in a defined order.

* `data/` *(structure tracked, contents kept local)*
  Data storage (files in this folder are ignored by Git; only the folder skeleton is kept via `.gitkeep`).

  * `data/metadata/` — reference tables (`sample_manifest.csv`)
  * `data/raw/` — raw input files
  * `data/processed/` — processed/intermediate datasets

* `output/` *(structure tracked, contents kept local)*
  Outputs generated by scripts (ignored by Git; only the folder skeleton is kept via `.gitkeep`).

  * `output/figures/` — plots and figures
  * `output/tables/` — non-figure results (e.g., CSV summaries, exported tables)

## Workflow overview

The workflow is executed by running scripts in the `scripts/` folder in numeric order.

General rule:

1. Put raw input files into `data/raw/`
2. Run scripts from `scripts/` in ascending order
3. Inspect results in `data/` and `output/` (local outputs)

## Script order and responsibilities

* `scripts/01_make_manifest.R`
  Scans `data/raw/` for `*.csv` files and builds/updates a local manifest at `data/metadata/sample_manifest.csv`.
  The manifest parses key fields from the filename:

  * `line`
  * `individual`
  * `replicate`
  * `drying` (P = air-dried/C = oven-dried/L = lyophilized)
  * `ageing` (T = temperature/H = humidity/B = both)

## Notes

* `data/` and `output/` contents are intentionally excluded from version control via `.gitignore`.
* To keep the directory skeleton visible, `.gitkeep` files are tracked in the relevant folders.
* When adding new scripts, keep the numbering convention (`02_...`, `03_...`) and document them above.
